# health-log

日付ごとの食事・栄養を記録する、日本語の静的サイト。HTML / CSS / JavaScriptのみで動き、外部ライブラリーやビルドは不要です。

## 開き方

`index.html` をブラウザーで開きます。安定した保存先を使うには、Node.jsがある環境で `npm start` を実行し、`http://127.0.0.1:4173/health-log/` を開いてください。

GitHub Pagesを利用する場合は、リポジトリの **Settings → Pages → Deploy from a branch → main / (root)** を選択します。URLは設定後にGitHubが表示するものを使用してください。相対パスのため `/health-log/` 配下でも動きます。

## 使い方

- カレンダーで日付を選び、「食事を記録」から名前と栄養値を入力。1食品ずつでも、食事全体を1件でも記録できます。
- 記録は編集・削除できます。未確認の栄養素は**空欄**にし、0とは区別します。
- 当日の合計・目標に対する割合・前日との差を表示。点線が100%で、超過量に合わせてバーの縮尺が広がります。食塩は上限なので100%到達を強調します。
- 「目標を設定」から初期目標を変更できます。食物繊維の目標は任意です。
- バックアップはJSONとして書き出し／読み込みできます。読み込みは現在の全記録と目標を置き換え、確認を表示します。

## 保存について

入力内容は**使用中のブラウザーのlocalStorageのみ**に保存。GitHubへの自動書き込み、アカウント同期はありません。端末・ブラウザー・URLが変わると別の保存先になります。ブラウザーのデータ削除で消えるため、定期的にバックアップしてください。保存失敗時には画面に通知します。不正な保存データは自動上書きせず、初期データを一時表示します。

このリポジトリには2026-09-12の初期食事データが含まれます。`data.js` を更新しても、既に保存されているブラウザーの記録を上書きしません。継続的にリポジトリへ記録を反映するには、バックアップの内容を確認して `data.js` を編集・コミットします。

## 初期データと塩分

カロリー・PFCは本人提供の概算を維持：**1391kcal / P45g / F64g / C170g**。初期目標は2100kcal / P70g / F55g / C275g / 食塩6g未満です。

塩分は朝食約0.7g（味未指定、参考0.44〜0.94g）、昼食約0.7g（公式全量0.98g、ドレッシング半量、参考0.49〜0.98g）、間食1g（該当豆腐バー公式値、バナナは0gと仮定）。夕食はそばの製品と汁の残量などが不明のため `null`。「汁は飲み干していない」を記録。**約2.4gは3食の判明分であり、日全体の食塩摂取量ではありません。** 食物繊維も全量が不明なため `null` です。推定根拠・公式リンクはサイト内「初期データと推定値について」を参照（確認日2026-09-12）。商品の改訂・地域差があるため手元の包装を優先してください。

## 構成・拡張

- `index.html`：画面構成、出典・推定方法
- `styles.css`：PC・スマホ用デザイン
- `data.js`：初期目標・食事（`date`, `category`, `name`, `nutrients`, `estimated`, `note`）
- `model.js`：栄養素定義、合算、日付計算、バックアップ検証
- `app.js`：描画、編集、保存、取り込み

栄養素は `nutrients` のキーで管理。追加時は `model.js` の定義・`data.js` の目標／初期値・既存バックアップの移行を更新します。未確認は `null`。表示・入力欄・比較は定義から生成されます。名前・メモはHTMLとして実行せずテキストとして表示します。

## 確認

`npm test`：初期合計、未確認と0の区別、日付境界、バックアップ往復、不正データの検証。
ブラウザーでは追加・編集・削除、リロード保存、日付・月の切替、前日比較、目標変更、JSON入出力、PC・スマホ表示を確認します。
